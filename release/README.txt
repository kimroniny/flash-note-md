闪记 —— 开会用的 Markdown 笔记（所写即所见）

1. 双击 FlashNote-Setup.exe 覆盖安装（不用管理员）
2. 桌面 / 开始菜单会出现「闪记」
3. 打开就能写：当前段是原文，其它段立刻排版

便携版：FlashNote.exe 直接双击。
卸载：Windows 设置 → 应用 → 闪记

写法：# 标题  **强调**  `代码`  - 列表  - [ ] 待办
Ctrl+N 新建会议，Ctrl+; 插入时间，Ctrl+S 保存。

需要 Microsoft Edge 或 WebView2 运行时。
笔记存在 %LOCALAPPDATA%\FlashNote\webview2
