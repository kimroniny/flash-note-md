闪记 —— 开会用的 Markdown 笔记（所写即所见）

1. 双击 FlashNote-Setup.exe 覆盖安装（不用管理员）
2. 默认把笔记存在「文档\闪记」，可在应用里点「存储」改目录
3. 打开后中间是最近笔记。点 + 新建空白笔记，标题自己打。左侧「设置」改存储目录、主题、字体、字号；「导出」下载当前笔记；列表里 Tab 缩进

便携版：FlashNote.exe 直接双击。
卸载：Windows 设置 → 应用 → 闪记

写法会边打边排版：# 标题  - 列表  - [ ] 待办  > 引用  **强调**  *斜体*  `代码`
Ctrl+N 新建会议，Ctrl+W 关闭当前标签，Ctrl+; 插入时间，Ctrl+S 保存。点笔记会在顶栏打开标签，可同时开多篇。
